 # Игра "Угадай число"
 ## Простая консольная игра, в которой игроку нужно угадать случайное число от 1 до 100 за ограниченное количество попыток.
 ### Фичи, возможности игры
 - **Выбор уровней сложности** (Easy, Medium, Hard), которые меняют количество попыток и диапазон чисел.
 - **Валидация пользовательского ввода** (программа не падает, если ввести буквы вместо числа).
 - **Цветовая раскраска консоли** (🔥 Горячо, ❄️ Холодно) для удобства пользователя.
 - **Сохранение истории игр в JSON-файл** с автоматической генерацией ID для каждой новой сессии.
## Как запустить проект?
1. Склонировать проект:
```bash
git clone <путь к репозиторию>
```
2. Скачайте зависимости:
```bash
go mod tidy
```
3. Запустите игру:
```bash
go run main.go
```

## Архитектура проекта
- `game()` — основной цикл игры.
- `getUserInput()` — ввод чисел пользователем.
- `printHint()` — логика расчёта близости к секретному числу.
- `saveResult()` — сохранение итогов игры в json файл
## Используемые технологии:
- **Язык программирования:** Go (версия 1.21 и выше, используется пакет `math/rand/v2`).
- **Стандартная библиотека:** `encoding/json`, `os`, `strconv`, `time`, `fmt`.
- **Внешние зависимости:** `github.com/fatih/color` — для цветного вывода в терминал.
